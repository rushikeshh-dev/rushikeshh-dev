## About Me

I'm a **Final Year AI & Data Science engineering student** who got tired of only *reading* about infrastructure and decided to run it myself. That instinct turned into **CloudNest** — a self-hosted personal cloud running on bare-metal Ubuntu, and it's the reason my direction has shifted from "just AI/ML" toward **Cloud & DevOps**, where I get to combine the two: deploying, monitoring, and operating the systems that AI/ML workloads actually run on.
